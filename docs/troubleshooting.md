## 設置・セットアップ

| 表示される内容 | 原因と対処 |
|---|---|
| 「vendor フォルダが見つかりません」 | リポジトリのソースをそのまま置いています。Releases の配布用 zip を設置してください |
| 「設置設定を確認してください」 | `.htaccess` の転送が効いていません。mod_rewrite と AllowOverride を有効にするか、公開フォルダを `public/` に指定してください |
| 「セットアップを開始できません」（フォルダに書き込めません） | `storage/` 配下と `bootstrap/cache/` のパーミッションを 755（環境によっては 775）にしてください |
| 「設定ファイルが外部から見えないこと」が **NG** | `.env` などが外から読める状態です。解決するまで先へ進めません。上と同じく `.htaccess` か公開フォルダを見直してください |
| 同じ項目が **要確認** | サーバーが自分自身へアクセスできない環境です。表示されたリンクを開き、ファイルの中身が表示されないことを確認してチェックを入れてください |
| 「サブドメインの向き先」が **注意** | サブドメインの公開フォルダが未設定か、DNS・SSL がまだ反映されていません。後から設定しても構いません |
| 「ページの有効期限が切れました」（419） | 最初にアクセスしたときと違うスキーム（http / https）で開いています。最初と同じ URL で開き直してください |

## ログイン

| 症状 | 原因と対処 |
|---|---|
| 「Discord ログインが設定されていません」 | 保存済みの Client ID / Secret を読み出せません（`.env` の `APP_KEY` を変更した場合など）。`APP_KEY` を元に戻してください。管理者がまだいない場合は `dash.〜/login` で設定画面が開きます |
| Discord で「Invalid OAuth2 redirect_uri」 | Discord Developer Portal の Redirects に、設定画面や「外部サービス」に表示されている URL を登録してください |
| ログインしてもダッシュボードに入れない | ダッシュボードのドメインがメインドメインのサブドメインでない場合、ログイン状態を共有できません。`.env` の `SESSION_DOMAIN` を確認してください |

## 発行・転送

| 症状 | 原因と対処 |
|---|---|
| 「スパム対策の確認に失敗しました」 | reCAPTCHA のキーが正しくないか、ブラウザが Google のスクリプトを読み込めていません。「外部サービス」で保存し直すと、その場で設定を確認できます |
| 転送時に毎回「安全性を確認できませんでした」 | Safe Browsing の API キーが未設定か、キーの制限で使えません。「外部サービス」を確認してください |
| 統計に国が出ない | 判定用データベースの取得がまだ済んでいません。「外部サービス」の「今すぐ取得する」で取得できます |
| 自分のサイトの URL を短縮できない | 転送が循環するため、設定した4つのドメインの URL は短縮できません |
| 更新した直後から 500 エラーになる | テーブルの更新が済んでいません。通常は次のアクセスで自動的に適用されますが、失敗した場合はログに「データベースの更新に失敗しました」と残ります。原因を直したうえで `php artisan migrate --force` を実行するか、10分ほど待ってから開き直してください |

## 自動アップデート

| 症状 | 原因と対処 |
|---|---|
| 動かない | 「アップデート」画面の「前回の定期処理」と、トークン・有効化の設定を確認してください。実行履歴にエラー内容が残ります |
| 「前回の定期処理」がずっと更新されない | サーバーが自分自身へ接続できない環境かもしれません（PHP-FPM 以外）。cron（`php artisan schedule:run`）を登録してください |
| 更新に失敗した | 自動でバックアップから元に戻し、Discord に通知します。実行履歴のエラー内容を確認し、解決してから「最新リリースを確認」で再実行してください |

## 開発環境（Windows）

- **PHP / Composer で `certificate verify failed`**: ウイルス対策ソフトの HTTPS スキャンが独自の証明書で通信を中継していることがあります。Windows が信頼しているルート証明書を CA バンドルに追加し、`php.ini` の `openssl.cafile` と `curl.cainfo` に指定してください（証明書の検証自体は無効にしないでください）。
- **Composer で `Could not delete ... antivirus`**: ウイルス対策ソフトが展開中のファイルをロックしています。除外設定を行うか、配布用 zip は GitHub Actions で作成してください。

## それでも解決しないとき

[GitHub の Issues](https://github.com/choko1229/URL-Shortener/issues) に、次の情報を添えて報告してください。

- 設置している環境（サーバー、PHP のバージョン、設置方法）
- 表示されたメッセージ
- `storage/logs/laravel.log` の該当部分（`.env` の内容やキーは貼らないでください）
