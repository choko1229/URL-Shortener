# chok.ooo

自分のサーバーに置いて使える、シンプルなURL短縮サービスです。ファイルを設置してブラウザで開き、データベースの接続情報を入力するだけで使いはじめられます。サーバー側での Composer・Node.js・SSH・cron の設定は必要ありません。

作者は [chok.ooo](https://chok.ooo) として運用していますが、**設置した人が自分のサービスとして使えるように作ってあります**。サイト名・運営者名・利用規約・プライバシーポリシーは、設置後に管理画面から変更できます。

[インストール手順を見る](install.html){: .btn .btn-primary }
[GitHub リポジトリ](https://github.com/choko1229/URL-Shortener){: .btn }

## できること

| 機能 | 内容 |
|---|---|
| 短縮URLの発行 | ランダムコード（7桁）。ログインするとカスタムスラッグ（3〜20文字）と無期限も使えます |
| 有効期限 | 発行時に指定。未ログインの場合は最大30日。期限切れは専用ページを表示します |
| パスワード保護 | 誰でも設定できます。5回間違えると15分間ロックします |
| 転送前の安全確認 | 中間ページから確認用サブドメインへ進み、Google Safe Browsing で転送先を確認します |
| 統計 | クリック数・日別推移・リファラ・国・デバイス種別 |
| QRコード | 発行時・ダッシュボードで表示し、SVG / PNG を選んでダウンロードできます |
| 共有時のカード | Discord や X に貼ったときの表示を、リンクごとに選べます（転送先のカードを見せる／隠す／内容を指定する） |
| ログイン | Discord のみ。最初にログインした人が管理者になります |
| 管理者機能 | 全URLの管理、ユーザーの昇格、予約語、APIキー、サイト設定、お問い合わせ、外部サービス、アップデート |
| API | 管理者専用。他のプロジェクトから短縮URLを発行できます |
| 自動アップデート | 1日1回 GitHub Releases を確認し、バックアップ → 更新 → 動作確認。失敗したら自動で元に戻します。更新元は設定済みで、追加の設定は要りません |

## 4つのサブドメインを使います

1つのアプリケーションで、次の4つのドメインを扱います。すべて同じフォルダを公開するように設定します。

| 例 | 役割 |
|---|---|
| `example.com` | トップページ（発行フォーム）、短縮URLへのアクセス受付、お問い合わせなど |
| `dash.example.com` | ログインとダッシュボード、管理者機能 |
| `api.example.com` | 管理者専用 API |
| `redirect.example.com` | 転送前の確認と安全確認 |

## 動作環境

- PHP 8.2 以上（`pdo_mysql` `mbstring` `openssl` `zip` などの標準的な拡張モジュール）
- MySQL 8.0
- Apache（`.htaccess` が使えること）。nginx でも、公開フォルダを `public/` に指定すれば動きます
- HTTPS（Cookie の保護設定に使うため、設定を強くおすすめします）

レンタルサーバーでの利用を想定しています。作者は kagoya で運用する予定です。
