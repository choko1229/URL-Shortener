設置した人が自分のサービスとして運用できるよう、表示名と文章は管理画面から変更できます。コードを書き換える必要はありません。

## サイトの表示

「管理」の「サイト設定」タブ（管理者のみ）で変更します。

| 項目 | 使われる場所 | 未設定のとき |
|---|---|---|
| サイト名 | ヘッダーのロゴ、ページタイトル、Discord への通知、「自身の URL は短縮できません」などのメッセージ | メインドメイン（例: `example.com`） |
| キャッチコピー | トップページのタイトル「サイト名 - キャッチコピー」 | シンプルなURL短縮サービス |
| 運営者名 | 利用規約・プライバシーポリシーの表示 | サイト名と同じ |

`.env` で既定値を決めることもできます（`SHORTENER_SITE_NAME` `SHORTENER_SITE_TAGLINE` `SHORTENER_OPERATOR_NAME`）。管理画面の設定があればそちらが優先されます。

## 見た目（カラー・ダークモード・書体）

同じ「サイト設定」の画面で変更します。保存するとすぐ反映されます（ビルドし直す必要はありません）。

### メインカラー

用意した6色から選ぶか、カラーコード（`#2ec5e0` の形式）で指定します。ボタンの濃い色、背景の薄い色、枠線の色、表の罫線などは、この1色から自動で作ります。

文字に使う色は、背景との明度差（コントラスト比 4.5:1、WCAG AA）を満たすまで自動で暗く（ダークでは明るく）調整します。極端に明るい色や暗い色を選んでも、文字が読めなくなることはありません。

### ダークモード

| 設定 | 動作 |
|---|---|
| ライトのみ（既定） | ダークにしません。切り替えボタンも出しません |
| 閲覧者の端末の設定に合わせる | OS がダークモードならダークで表示します |
| ダークを既定にする | 初めての訪問者にもダークで表示します |

「ライトのみ」以外を選ぶと、ヘッダーに切り替えボタンが出て、訪問者が自分で選べます。選択はその人のブラウザにだけ記憶します。ダークの配色もメインカラーから自動で作ります。

### 書体

丸ゴシック（既定）・ゴシック・角ゴシック・やわらかい丸ゴシック・明朝から選べます。いずれも Google Fonts の日本語フォントで、見出しと本文の組み合わせが変わります。

## サービスアイコン

ヘッダーのロゴマークです。ブラウザのタブに出るファビコンにも同じものを使います。

- **内蔵アイコンから選ぶ**: 6種類から選びます。メインカラーの四角に白抜きで表示します。
- **画像を使う**: PNG / JPG / WebP を 512KB まで。正方形（512×512 程度）がきれいに表示されます。

画像は公開フォルダではなく `storage/app/private/branding/` に保存し、アプリ経由で配信します（`storage:link` が使えないサーバーでも動くようにするためです）。SVG は中にスクリプトを書けるため受け付けません。

## 限定モード（自分や身内だけで使う）

自分専用の短縮URLドメインとして使いたい場合は、「サイト設定」の「公開範囲」で **限定モード** にします。

| | 公開（既定） | 限定モード |
|---|---|---|
| 発行・ダッシュボード | ログインしていない人も発行できる | 管理者と、許可したユーザーだけ |
| 発行済みの短縮URL | 誰でも開ける | 誰でも開ける |
| 利用規約・プライバシーポリシー・お問い合わせ・QRコード | 誰でも開ける | 誰でも開ける |

限定モードで、許可されていない人がトップページやダッシュボードを開いたときの動作を選べます。

- **このドメインの説明を表示する**（既定）: 同じ画面の「このドメインについて」を表示します。本文は利用規約と同じく **Markdown** で書け、「テンプレートを入力」でひな形も読み込めます。未作成のときは短い既定の文を表示します。
- **別のURLへ移動する**: 本来のサイトやポートフォリオなどへ移動させます。このサイト自身の URL は指定できません（移動を繰り返してしまうため）。

### 利用を許可する

1. 使わせたい人に、`dash.〜/login` から一度 Discord でログインしてもらいます（限定モードではダッシュボードを開いてもログイン画面には案内しないため、このアドレスを直接伝えてください）。許可されていないのでログインは断られますが、「ユーザー」タブに表示されるようになります。
2. 「管理」の「ユーザー」タブで、その人の「限定モードでの利用」を「許可する」にします。
3. もう一度ログインしてもらうと使えます。

管理者は常に使えます。限定モードに切り替えたとき、許可されていない人がログインしたままだった場合は、次に開いたときにログアウトします。

## 利用規約・プライバシーポリシー

同じ「サイト設定」の画面で、本文を **Markdown** で編集します。

1. 「テンプレートを入力」を押すと、ひな形が編集欄に読み込まれます（この時点では保存されません）。サイト名と運営者名は自動で差し込まれます。
2. 内容を確認し、運営の実態に合わせて修正します。
3. 「保存する」を押すと公開され、フッターにリンクが表示されます。

未作成のページは公開されません（開くと 404 になり、フッターにも出ません）。「ページを削除する」で非公開に戻せます。

{: .warning }
> テンプレートは、このソフトウェアが実際に行っている処理（保存する情報、外部への送信、削除の扱いなど）に沿った下書きです。法律の専門家が作成したものではなく、そのまま使えることを保証するものではありません。公開前に必ず内容を確認してください。

### 使える書き方

| 書き方 | 表示 |
|---|---|
| `## 見出し` | 見出し |
| `- 項目` | 箇条書き |
| `1. 項目` | 番号付きの箇条書き |
| `[表示する文字](https://example.com)` | リンク |
| `**強調**` | 強調 |
| `> 引用` | 引用 |

本文に書いた HTML は、表示するときに取り除きます（`javascript:` で始まるリンクも無効にします）。

## お問い合わせ

お問い合わせページ（`/contact`）は最初から使えます。メール送信（SMTP）の設定は必要ありません。

- 送信された内容はデータベースに保存され、「管理」の「お問い合わせ」タブで読めます。対応済み・未対応を切り替えられます。
- Discord の Webhook を設定していると、届いたときに通知します（[外部サービス](services.html)を参照）。
- 「お問い合わせ」画面の上部で、公開する Discord の連絡先（ユーザー名や招待リンク）を設定できます。設定するとお問い合わせページに表示されます。
- 未ログインからの送信には reCAPTCHA を適用します（設定している場合）。送信は10分に5回までです。

## 共有時のカード（OGP）

短縮URLを Discord や X に貼ったときの表示を、リンクごとに選べます。発行フォームの「共有時のカード」か、ダッシュボードのリンク詳細画面で変更します。

| 選択肢 | 表示されるもの |
|---|---|
| 転送先のカードを見せる（既定） | 転送先ページのタイトルや画像。カードを取りに来たクローラーだけを転送先へ通します |
| カードを隠す | サービス名だけのカード。転送先は出ません |
| 内容を指定する | 入力したタイトル・説明・画像 |

- パスワード保護をつけたリンクは、設定にかかわらず「隠す」として扱います（貼っただけで転送先が分かってしまわないようにするため）。
- 人がアクセスしたときの動き（中間ページ → 安全確認 → 転送）は、どの設定でも変わりません。カードの取得はクリック数に数えません。

## QRコードのダウンロード

発行直後のダイアログと、ダッシュボードの QR ボタンから、**SVG** と **PNG** を選んでダウンロードできます。URL を直接叩くこともできます。

| 形式 | URL | 向いている用途 |
|---|---|---|
| SVG | `https://example.com/{コード}/qr.svg` | 印刷など、拡大しても粗くならない |
| PNG | `https://example.com/{コード}/qr.png` | 画像として貼り付けやすい |

PNG の生成には PHP の GD 拡張が必要です。使えないサーバーでは SVG のみ表示します。

## 予約語

カスタムスラッグとして使えない語は、「管理」の「予約語」タブで追加・削除できます。大文字小文字は区別せずに判定します。管理者だけは予約語もカスタムスラッグとして使えます。

初期状態では、システム関連（`api` `admin` など）、認証関連（`login` `logout` など）、アプリのパスと衝突する語（`install` `contact` など）を登録しています。

## 利用制限の変更

発行できる件数やレート制限の初期値は `config/shortener.php` にあります。変更するにはファイルを編集します（`.env` には書きません）。

| 設定 | 初期値 |
|---|---|
| ログインユーザーの月間上限 | 60件 |
| ログインユーザーのレート制限 | 5回/分 |
| 未ログインの月間上限 | 5件（IP 単位） |
| 未ログインのレート制限 | 3分に1回 |
| 未ログインの最大有効期限 | 30日 |
| パスワードの試行回数 | 5回で15分ロック |

{: .note }
> アップデートするとこのファイルは新しいものに置き換わります。変更した場合は、アップデート後に再度適用してください。
