## 定期処理

次の処理は、サイトへのアクセスをきっかけに自動で実行されます（cron は使いません）。

| 処理 | タイミング |
|---|---|
| 自動アップデートの確認 | 1日1回（日本時間 4:00 を過ぎてから最初のアクセス時） |
| 国判定データベースの取得・更新 | 無ければすぐに（失敗したら1時間ごとに再試行）、以後は毎月新しい版が出たら |

しくみは次のとおりです。

- PHP-FPM / LiteSpeed の環境では、訪問者へ応答を返し終えた後に同じプロセスで実行するため、訪問者を待たせません。
- それ以外の環境では、自分自身へ合言葉（`APP_KEY` から生成）付きのリクエスト（`POST /_cron`）を送り、そちらで実行します。この合言葉が合わない要求は 404 を返します。
- 実行が必要かの確認は数分に1回だけ行うため、通常のアクセスに負荷はかかりません。
- 前回の実行時刻と、実行のきっかけ（cron／アクセス時）は「アップデート」画面に表示します。

### テーブルの自動更新

新しい版でテーブルの変更がある場合、更新後の最初のアクセスで自動的に適用します（`php artisan migrate --force` と同じ処理）。自動アップデートを使わず、配布用 zip を手作業で上書きした場合もこれで済みます。

同時に複数実行されないようロックを取り、失敗したときはログに記録して10分後に再び試みます。

アクセスが少ないサイトで時刻どおりに実行したい場合は、cron を登録することもできます。登録されていれば cron を優先し、アクセスでの実行は止まります。

```
* * * * * cd /path/to/url-shortener && php artisan schedule:run >> /dev/null 2>&1
```

cron だけで動かしたい場合は `.env` に `SHORTENER_WEB_CRON=false` を設定します。

## 自動アップデート

GitHub Releases に新しいリリースが出たとき、次の順で更新します。

1. 最新リリース（`vYY.MM.patch` 形式のタグ）を確認します。現在より新しくなければ何もしません。更新元（`choko1229/URL-Shortener`）は設定済みで、追加の設定なしで動きます。
2. バックアップを取ります（`storage/app/private/backups/`、直近3世代を保持）。
   - データベース: `mysqldump` を使い、使えないサーバーでは PHP で同等のダンプを作ります。
   - コード一式: `app` `bootstrap` `config` `database` `public` `resources` `routes` `vendor` と直下のファイル。
3. 新しいリリースを配置します。
   - Git で設置した環境: `git fetch` → 新しいタグへ `git checkout` → `composer install --no-dev`
   - 配布用 zip で設置した環境: Releases に添付された zip（ライブラリ同梱）をダウンロードして入れ替え
4. `php artisan migrate --force` でデータベースを更新します。
5. 動作確認（データベース接続、仮の短縮URLの発行と検索、表示ファイルの有無）を行います。
6. 成功したら Discord に通知します。失敗したら、コードとデータベースをバックアップから戻し、「失敗（ロールバック済み）」を通知します。

### 今すぐ更新する

翌日の定期処理を待たずに更新したいときは、「管理」の「アップデート」タブで **「今すぐ更新する」** を押します。自動アップデートを無効にしていても実行します。処理の内容は上と同じ（バックアップ →更新 →動作確認、失敗時はロールバック）で、完了まで数分かかることがあります。

### 設定

「管理」の「アップデート」タブで設定します。

| 項目 | 内容 |
|---|---|
| 自動アップデート | 有効・無効の切り替え |
| GitHub リポジトリ | 更新元（所有者/リポジトリ名） |
| GitHub のトークン | 任意。非公開リポジトリから取得する場合に必要（Fine-grained トークン／Contents: Read） |
| 通知先 | Discord の Webhook URL |

フォークして自分のリポジトリから更新する場合は、「GitHub リポジトリ」を自分のもの（`所有者/リポジトリ名`）に変更してください。非公開リポジトリの場合はトークンも設定します。

### SSH が使える場合のコマンド

| コマンド | 内容 |
|---|---|
| `php artisan app:update --check` | 最新リリースの確認のみ |
| `php artisan app:update --manual` | 自動アップデートが無効でも今すぐ実行 |
| `php artisan app:health-check` | 動作確認のみ |
| `php artisan app:periodic-tasks` | 定期処理を今すぐ実行 |

PHP（CLI）の場所は自動で探します。見つからない環境では、Web の処理の中で実行します。場所を指定したい場合は `.env` の `SHORTENER_PHP_BINARY` などで設定します。

## バックアップ

自動アップデートのたびに、直近3世代のバックアップを `storage/app/private/backups/` に作ります。世代数は `config/shortener.php` で変更できます。

これはアップデート前後の切り戻し用です。サーバー障害に備える定期バックアップは、レンタルサーバーのバックアップ機能などを別途ご利用ください。少なくとも次の2つは、必ず控えを取っておいてください。

- `.env`（`APP_KEY` とデータベースのパスワード）
- データベース

## ログ

`storage/logs/laravel.log` に記録します。発行・転送・ログイン・設定変更・定期処理・アップデートの結果などが残ります。パスワードやトークンなどの秘密情報は記録しません。

## データの扱い

- 削除した短縮URLは記録として残し（論理削除）、そのコードは二度と再利用しません。
- 退会したユーザーの Discord 由来の情報は削除します。発行した短縮URLを一緒に削除するかは、退会時に選べます。
- クリックの記録に IP アドレスと User-Agent は保存しません（国とデバイス種別だけを保存します）。
